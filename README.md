# HTML 可视化编辑器 · 桌面客户端

在本机打开和编辑 HTML 页面，支持文字样式、布局调整、历史版本、AI 说明与业务图解。

当前暂停公开下载，正在准备支持邀请码注册及限时试用的新客户端。原免费预览包已收起，待授权流程和安装验证完成后再开放。

本仓库仅用于发布安装包和使用说明，不包含编辑器开发源码。后续安装包会在 [Releases](https://github.com/hanfeng1865/html-visual-editor-releases/releases) 提供。

| 电脑 | 选择安装包 |
|---|---|
| Windows 64 位 | 名称包含 `win-x64` 的 `.exe` |
| Mac，Apple M 系列芯片 | 名称包含 `mac-arm64` 的 `.dmg` |
| Mac，Intel 芯片 | 名称包含 `mac-x64` 的 `.dmg` |

安装后打开“HTML 可视化编辑器”，选择自己的 HTML 项目文件夹即可使用。不需要另装 Node.js，也不需要在终端运行命令。AI 功能需自行配置支持的模型服务；相关资料会发送到你选择的模型服务。

当前为免费体验版，允许个人、公司日常工作及商业项目使用，禁止转卖软件。未来可能推出付费版本或服务，收费范围、价格和已有用户安排会另行公布；当前没有订阅扣款或强制到期。

项目保存在你选择的文件夹中，应用设置和最近项目保存在本机用户数据目录。菜单可“打开数据目录”或“检查更新”；首版更新需要下载安装包后手动安装。

预览版尚未完成 Apple 公证及 Windows 发布者签名，系统可能拦截安装。面向普通用户的正式发布将在完成签名后提供；请勿为安装而关闭系统安全保护。每个平台实际构建及运行验证情况见对应版本发布说明。

请保留重要项目的独立备份，具体使用范围与第三方声明随客户端提供。
