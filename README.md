# HTML 可视化编辑器 · 桌面客户端

在本机打开和编辑 HTML 页面，支持文字样式、布局调整、历史版本、AI 说明与业务图解。

最新体验版：[1.3.0-beta.8](https://github.com/hanfeng1865/html-visual-editor-releases/releases/tag/v1.3.0-beta.8)。本版修复大型项目 AI 修改报 HTTP 400 和预览页面链接无响应的问题；新增客户端右上角“一键更新”，点击后下载、安装并自动重新打开。

安装包请从 [Releases 下载](https://github.com/hanfeng1865/html-visual-editor-releases/releases)。本仓库仅用于发布安装包和使用说明，不包含编辑器开发源码。

| 电脑 | 选择安装包 |
|---|---|
| Windows 64 位 | 名称包含 `win-x64` 的 `.exe` |
| Mac，Apple M 系列芯片 | 名称包含 `mac-arm64` 的 `.dmg` |
| Mac，Intel 芯片 | 名称包含 `mac-x64` 的 `.dmg` |

系统要求：`1.3.0-beta.3` 及后续兼容版本支持 macOS 12（Monterey）及以上；Windows 需要 Windows 10 或以上的 64 位系统。旧的 `1.3.0-beta.2` Mac 安装包需要 macOS 13 及以上，macOS 12 用户请选择新版。

Mac 用户请选择 `1.3.0-beta.5` 或后续版本：beta.3 和 beta.4 存在安装包签名结构不完整的问题，可触发“已损坏，无法打开”。beta.5 修正了完整性签名，并检查 DMG 和 ZIP 内的应用，但尚未完成 Apple 开发者认证和公证，首次打开仍可能被系统拦截。

Mac 下载 DMG 后，将应用拖入“应用程序”，退出旧版后再从“应用程序”打开。若提示开发者无法验证或 Apple 无法检查恶意软件，请先核对下载来源，再到“系统设置 → 隐私与安全性”（旧系统为“系统偏好设置 → 安全性与隐私”）查看是否提供“仍要打开”，仅对本应用确认。如果没有此选项或仍提示“已损坏”，请保留提示和系统版本联系维护者，不要关闭系统安全保护。

下载中断或提示 403 时，请使用 Chrome、Edge 等浏览器打开 Releases 页面，直接点击对应安装包下载。若自动下载工具提示限流，可改用浏览器下载完整文件后再安装；未下载完整的文件无法安装，不需要因此重新兑换邀请码。

安装后打开“HTML 可视化编辑器”，点击顶部“登录 / 注册”。首次使用请选择“邀请码注册”，填写管理员提供的邀请码、账号和密码；之后使用账号密码登录。没有邀请码时请联系邀请你试用的人。不需要另装 Node.js，也不需要在终端运行命令。AI 功能需自行配置支持的模型服务；相关资料会发送到你选择的模型服务。

AI 修改页面时，如果提示回复被截断，可在“AI 对话 → 模型连接”中按服务商支持范围调大“页面修改回复上限”，保存连接设置后重新发送。留空使用服务默认值；此设置仅用于页面修改，不限制需求分析或业务图解生成，不支持该参数的接口请留空。设置不能突破模型或服务硬性上限，较大需求可分几次处理。

当前为邀请试用版，任何人都能下载安装包，编辑功能需要有效的账号权限。每个邀请码只能注册一个账号，默认兑换后试用 7 天，具体期限由管理员设置；每个账号最多使用 3 台设备。未登录、到期或停用后仍可查看和导出已有项目，不能新增、保存修改或使用 AI 生成。允许个人、公司日常工作及商业项目使用，禁止转卖软件。尚未接入付款或自动续费，未来收费安排另行公布。

项目保存在你选择的文件夹中，应用设置和最近项目保存在本机用户数据目录。菜单可“打开数据目录”或“检查更新”。beta.8 启动约 15 秒后检查更新，随后每 4 小时检查一次；有新版时右上角出现“一键更新”，无新版时隐藏。点击后下载、安装并重新打开；未保存修改、任务或编辑面板会阻止重启，已有下载会保留。beta.7 及更早版本需要先手动安装一次新版，之后才能使用此入口。已有账号无需重新兑换邀请码；Mac 更新后如出现钥匙串授权提示，请在系统弹窗中授权，以读取原有登录信息。

预览版尚未完成 Apple 公证及 Windows 发布者签名，系统可能拦截安装。面向普通用户的正式发布将在完成签名后提供；请勿为安装而关闭系统安全保护。每个平台实际构建及运行验证情况见对应版本发布说明。

请保留重要项目的独立备份，具体使用范围与第三方声明随客户端提供。
